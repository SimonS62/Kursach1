# Финансовый менеджер (ProjectKursach1)

## Описание проекта
Это учебный проект — финансовый менеджер, предназначенный для отслеживания расходов, анализа транзакций, получения актуальных курсов валют и цен акций. Проект реализован на Python и включает функции для работы с финансовыми данными, а также тесты для проверки корректности работы.

---

## Основные функции
- Подсчет общих расходов за выбранный период
- Получение топ-5 транзакций по сумме
- Определение времени суток для приветствия пользователя
- Форматирование номера карты (последние 4 цифры)
- Расчет кешбэка по расходам
- Получение актуальных курсов валют с API
- Получение цен акций с API

## Установка:

1. Клонируйте репозиторий:
```
git clone https://git@github.com:SimonS62/Kursach1.git
```
2. Установите зависимости:
```
poetry install 
```
3. Создайте виртуальное окружение (по желанию)

4. Установите необходимые библиотеки

---

## Использование:
Запустите основной скрипт:

    bash:
    python main.py

---

## Тестирование:
Для запуска тестов используйте:

    bash:
    python -m unittest discover tests/
    # или с pytest:
    pytest tests/
